# Aula 3 · Do HTML ao dado: ler a tabela

Aula na plataforma: https://learn.gabrielgreco.com/learn/trilha/pw-03-do-html-ao-dado-ler-a

Como tirar um dado do HTML guardado? Escolha da biblioteca, o seletor da tabela e a linha do Acre como dicionário.

A pasta `projeto/` mostra como a sua pasta `projeto-wikipedia/` deve estar no fim desta aula. Arquivos novos ou alterados nesta aula: ler.py.

## Como rodar esta pasta

```
cd projeto
cp .env.example .env
```

Abra o `.env` e troque o contato pelo seu (um e-mail ou o endereço do seu repositório). Depois:

```
uv sync
```

As aulas 3 em diante leem `dados/lista.html`. Se a pasta `dados/` ainda não existe, rode antes `uv run python baixar.py`.

Comando da aula: `uv run python ler.py`
